# Math Expressions Evaluator

lexer - implemented

parser - implemented

evaluator - implemented


The Basics of the program structure are implemented.


Handles simple math expressions, all with proper precedence.


# Expression examples:
    4 + 2.
    4 + 2 * 10.
    4 + 2 * 10 + 3 / 5 - 1.
    4 + 2 * 10 + 3 * (5 + 1) - 2.


# Edge Cases:
    % operator.
    ^ operator.
    negative numbers.
    parenthesis at the start of the expression.
