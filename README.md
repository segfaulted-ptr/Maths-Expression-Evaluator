# Math Expressions Evaluator

Tokenizer - implemented

Parser - implemented

Evaluator - implemented


The Basics of the program structure are implemented.

Gracefully handles simple math expressions with proper precedence.


# Expression examples:
    4 + 2
    4 + 2 * 10
    4 + 2 * 10 + 3 / 5 - 1.
    4 + 2 * 10 + 3 * (5 + 1) - 2
    (2 * 3 * 4) / (2 * 3 * 4)
